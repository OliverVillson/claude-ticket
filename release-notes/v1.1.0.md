## salu v1.1.0

Update: `salu update`, then `salu --version` and `salu doctor`.

### Tickets are threads
- A ticket can be **resolved** and **reopened**: `salu resolve "name"`, `salu reopen "name"` (#64).
- Workers get a `salu` tool: a checklist, decisions to ask you, outputs they produced, and sub-threads (#67).
- The TUI shows the thread view (checklist, decisions, outputs, sub-threads); the amber colour is gone, everything is green (#69).
- Threads sync over the git inbox like tickets do (#65).
- Project memory, shared files and `salu sync` (#66).

### Workers get the full Claude Code tools, fenced to the project
- Workers now have Claude Code's full toolset (#68).
- **Fenced mode is the default:** writes are confined to the project folder. Set `SALU_SANDBOX=off` to opt out (workers can then change any file you can).
- The OS-level part of the sandbox (Seatbelt on macOS, bubblewrap on Linux) is **untested on macOS**. Run `salu doctor --sandbox` after updating and tell us what it says.
