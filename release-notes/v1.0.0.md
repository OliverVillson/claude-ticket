## salu v1.0.0

Update on a Mac that already has v0.2.4 or newer: `salu update`. Older installs: re-run the installer once.

### Run tickets away from your computer
- **Runner:** `salu runner` runs a project unattended on a Linux box, one systemd orchestrator per project, sandboxed, starting on boot (#49).
- **Git sync:** `salu remote` sends tickets to the box and brings its messages back over the project's private `salu/inbox` branch. Every file is signed with a shared key (`salu remote add --box` makes it, `salu remote key` shows or rotates it) and unsigned files are ignored (#51, #61).
- **Subscription login on the box:** `claude setup-token` based login for the runner (#59).
- **Phone pings:** `salu remote ntfy` publishes each box message to a private ntfy topic (#60).
- Setup guide: `docs/v1-setup.md` (#56).

### Tickets
- `salu add` queues by default, and a finished ticket keeps its branch and a summary (#50).
- Tickets hold a conversation: `salu reply` and `r` in the TUI resume the same session on the same branch (#55).
- `salu notif` lists unread orchestrator messages (#52).
- Token-aware scheduler: estimates, window-aware dispatch and model routing (#57).
- Sandbox hardening and `salu doctor --sandbox` (#48), opt-in kernel sandbox with `salu push` and `salu export` (#46), the `a` key for blocked tickets in the TUI (#45).

### Not in this release
The iPhone app (SwiftUI, `ios/`) is still on open draft pull requests #53 and #54 and needs an Xcode build.
